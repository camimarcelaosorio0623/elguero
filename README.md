# El Güero · Divino Cantarito — propuesta de diseño v1

Landing de propuesta para **El Güero Divino Cantarito** (restaurante · bar · discoteca mexicana en Laureles, Medellín).
Concepto: *El Güero vs. El Hambre* en versión luxury: logo oficial, verde profundo + dorado, Cinzel / Libre Baskerville (alineado con divinocantarito.co).

Sitio estático (HTML + CSS + JS, sin dependencias). Para verlo en local:

```bash
python3 -m http.server 3031
# http://localhost:3031
```

Publicable tal cual en Cloudflare Pages / Netlify (directorio raíz, sin build).
